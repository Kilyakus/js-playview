# PlayView.js - v1.2610.09717

The player of the stack: plays video, audio and HLS streams in the container the host gives it, on Plyr with the HoldView state layer, and tells everything through events. Artwork, a PadView backdrop and an equalizer are optional; nothing is thrown — render() and play() resolve to false.
